# 02 · 用户流程与逐屏交互

## 1. 界面结构

主工作区保持单一课程上下文。左边为可折叠课程导航，中间为按需出现的修订区，右边为持续更新的转写与课堂资料。顶部只放课程名、音频来源、录音状态、模型状态和主要录音控制。

┌──────────────────────────────────────────────────────────────────────────┐
│ 课程名称      麦克风 · 本地模型     ● 录音 00:24:18      [停止录音]       │
├──────┬─────────────────────────┬─────────────────────────────────────────┤
│课程  │ 修订 · 00:23:42         │ 课堂记录                         本地保存│
│      │ 原识别 [展开]           │ 00:23:42                         编辑中 │
│      │                         │ According to Talmey ...                  │
│      │ According to Talmy ...  │                                         │
│      │                         │ 00:23:51                                │
│      │ 草稿已保存              │ The distinction concerns Path ...      │
│      │ [回放] [关闭] [保存修订]│                                         │
│      │                         │ 00:24:07                   正在识别     │
│      │                         │ In a satellite-framed language ...      │
│      │                         │                    [有 4 条新内容 ↓]    │
└──────┴─────────────────────────┴─────────────────────────────────────────┘

该线框表达信息关系；生产界面的排版按第 08 章实现。课程导航默认折叠；没有编辑任务时，修订区收起，转写占据主要空间。

## 2. 首次使用与开始课程

欢迎页提供本地工作说明、模型下载入口和音频权限检查。模型卡显示完整下载总量、预计磁盘占用与尚未测得的硬件性能状态。下载结束后校验全部文件，执行短音频识别测试，再显示可用。

新建课程页包含课程名、日期、音频来源、识别语言、术语表入口。预览电平条必须来自真实采集帧，模型加载进度与电平分别显示。授权失败、设备静音和模型未就绪均使用具体提示。模型加载较慢时可允许“先录音，稍后转写”，按钮旁明确显示该状态。

开始录音前展示简短的课程录音授权提醒。课程会话在数据库中建立后再开始采集；采集启动成功才显示“录音中”。

## 3. 取出一句或一段进行编辑

转写的最小可编辑单元称为“转写块”。一个块可包含一句或一个短分句，按音频边界确定，标点可以随后更新。每个块在悬停和键盘聚焦时显示“取出编辑”。点击始终绑定该块的稳定 ID。

打开时保存当前显示快照与基准识别版本。左侧输入框获得焦点，光标定位到用户点击或选中的词；没有明确词位置时选中整段与否由可用性试验确定，建议默认将光标放在末尾以减少误删。右侧原位保留相同内容和“编辑中”标识；新的块继续写入。

左侧编辑区的文字在整个编辑会话中保持稳定。后续模型结果进入数据层，右侧该块可以保持打开时的固定视觉快照，同时用“此段有新识别”提示；编辑会话结束后显示合并结果。其他块正常更新。

## 4. 保存与返回

用户点击“保存修订”或按 Cmd/Ctrl + Enter。收到数据库持久化确认后，左侧显示“已保存”，右侧原块显示修订后的内容。系统保持原块身份、音频范围与资料锚点。短暂的底色变化帮助定位；页面滚动位置保持稳定。

合并存在冲突时，保存仍可成功：用户文字成为当前展示，模型版本进入待核对列表。提示为“修订已保存，另有识别更新待核对”。课堂过程中使用非阻塞提示，禁止弹出要求立即选择的对话框。

建议默认保存后收起编辑区。用户可以开启“连续修订”模式，保存后保留面板。无论采用哪种模式，保存按钮均完成同一事务。

## 5. 草稿与关闭

草稿在最后一次输入后约 300 毫秒自动落盘，并在切换编辑对象、关闭面板、应用失去焦点时请求立即保存。300 毫秒属于建议默认值。草稿状态使用“正在保存草稿”和“草稿已保存”。

按 Escape 关闭面板并保留草稿。点击另一个块时，先持久化当前草稿，再切换。下次打开该块优先恢复草稿，并提示恢复时间。只有“放弃草稿”动作才清除草稿；它需要明确按钮，避免与关闭按钮混用。

只打开后直接保存、且文字没有变化时，执行无修改提交：结束编辑会话并显示最新安全投影，保持原有人工修订状态。

## 6. 待核对内容

顶栏的轻量计数入口显示待核对数量。每个条目展示音频时间、已保存文字、当前机器候选和变化位置。提供“保留当前文字”“采用此识别版本”“编辑合并”三个动作。

“保留当前文字”将用户当前文本相对于最新机器版本重新确认为修订；“采用此识别版本”会撤销该块的当前人工覆盖，操作进入撤销历史；“编辑合并”提供可编辑结果。三个动作均检查用户看到的机器版本号，版本变化时刷新比较内容并保留输入。

当前块的机器结果结束后，待核对提示持续保留到用户处理，课程结束和重新打开均保持一致。

## 7. 持续滚动

转写列表有“跟随最新”与“阅读旧内容”两个独立状态。用户在底部附近时追加内容跟随到底部；滚动到旧内容后保持当前位置，右下出现“有 N 条新内容”。N 统计新转写块，机器对同一块的多次修订只计一次。

打开修订区时记录滚动锚点，保存修订后恢复同一块及相对偏移。点击“回到最新”恢复跟随。新增字符、图片加载和公式高度变化均通过锚点补偿控制滚动。

课堂记录很长时采用按块虚拟化；正在编辑、获得键盘焦点或被读屏访问的块固定挂载，避免输入状态丢失。

## 8. 插入公式、图片与案例

每个块末尾有“添加资料”入口，提供备注、公式、图片、例子四种类型。创建动作立即确定锚点：目标块 ID、目标音频采样位置、前后关系及排序值。后续转写增加时锚点保持稳定。

资料区与转写区使用同一文档顺序，资料卡有轻量“笔记”“公式”或“例子”标签。用户可以写“教授举的例子”或“我的例子”，以区分来源。图片支持粘贴、拖入与文件选择，写入附件目录后才显示“已保存”。

用户正在输入公式时，模型继续运行。数学输入使用 LaTeX 源码编辑和旁侧或行内预览；渲染失败保留源码并标示错误位置。

## 9. 回放

点击时间戳回放相应转写块的音频范围，可设置前后各约 0.5 秒的上下文。没有可靠逐词时间戳时只提供整块定位。音频尚未可回放或录音源存在回授风险时，回放按钮显示原因和安全操作。

系统声音录音期间，回放默认受保护：只有当前系统方案已经可靠排除本应用输出时才允许直接播放。其余情况要求停止系统声音采集后回放。麦克风模式建议使用耳机，并提供回授提醒。

## 10. 结束、退出与恢复

“停止录音”结束采集并完成音频落盘；转写任务继续处理队列。状态分别显示“录音已结束”“转写处理中”“全部处理完成”。用户可在处理期间继续修改已生成内容。

活动录音时关闭窗口，显示保存并结束、继续录音并保留应用、取消三个选项；“继续录音”只有在对应系统后台存活、托盘或菜单栏状态已实现并验收后开放。强制退出后再次打开，先检查课程与音频，再进入恢复页面。

## 11. 键盘与输入法

| 动作 | 建议键位 | 作用条件 |
|---|---|---|
| 取出编辑 | Cmd/Ctrl + Shift + E | 选择的块，随后是聚焦块，最后是可见的最近稳定块 |
| 保存修订 | Cmd/Ctrl + Enter | 修订编辑框聚焦且输入法已经完成组合 |
| 关闭并保留草稿 | Escape | 没有上层菜单和输入法候选窗口 |
| 撤销 | Cmd/Ctrl + Z | 编辑器内部先撤销文字；离开编辑器后撤销人工文档动作 |
| 添加资料 | 块操作菜单 | 锚点明确，使用可见按钮与键盘菜单 |

首版不使用全局热键。任何录音停止动作均配有明确可见按钮。快捷键在实际 Windows 与 macOS 输入法、系统菜单和浏览器容器中测试后冻结。
