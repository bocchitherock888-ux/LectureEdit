# 10 · 接口协议与安全

## 1. 领域命令

前端通过类型化命令访问宿主。每条写命令带 `command_id`，相关人工修改带预期修订序号。`contracts/domain.ts` 提供共享对象与建议命令结构，正式仓库优先由 Rust 类型自动生成 TypeScript 类型。

| 命令 | 关键输入 | 成功结果 |
|---|---|---|
| create_session | 标题、语言、来源设置 | session ID |
| start_recording | session ID、设备与模型选择 | capture run ID、真实状态 |
| stop_recording | session ID、run ID | 音频关闭结果、积压状态 |
| begin_edit | segment ID | 固定快照、editor ID、用户序号 |
| save_draft | editor ID、draft revision、text | 持久化草稿版本 |
| commit_edit | editor ID、预期人工序号、text | 修订、展示、候选状态 |
| resolve_candidate | segment ID、预期机器版本、人工序号、动作 | 新人工状态 |
| add_note | 锚点、类型、内容、附件 | note ID |
| export_session | session ID、格式、快照序号 | 受控输出位置 |

错误采用固定 code、可理解 message、是否可重试与保留状态。内部堆栈和用户私密内容仅在用户明确导出诊断时提供。

## 2. 事件信封

事件包含 schema version、event ID、session ID、operation sequence、时间与 payload。机器输出额外带 worker epoch 和 hypothesis revision。领域事件在数据库提交后发送；临时 UI 进度可用单独 ephemeral 通道，并清楚区分。

前端按事件序号消费，重复事件去重。重连握手返回快照和最后序号，然后补发后续事件。旧序号、未知 schema 版本与跨课程事件进入错误处理路径。

## 3. 适配器能力声明

能力对象至少包括 engine ID、model ID、input mode、支持语言设置、时间戳粒度、热词支持、取消能力和流式输出类型。后端能力由实际实现定义，模型名本身不足以开启某项功能。

`chunked` 调用以确定音频范围与 base64 或受控内部路径传入；`native_streaming` 以会话句柄和采样帧传入。两类输出统一为完整转写快照，避免前端处理后端特有 token 拼接。

## 4. 本地服务请求

llama-server 的 `input_audio` 接口可接受音频数据；基准调用通过 Rust 读取已授权音频范围，构造 WAV 字节并进行 base64 编码。[S07] 限制每个请求音频长度、JSON 体积、响应长度与超时。禁用远程音频 URL 和任意本地文件路径输入。

所有服务请求携带本次启动的凭据。原生服务绑定回环地址，禁止监听所有网卡；禁用 Web UI、工具执行和其他不需要的服务功能。前端没有直接访问该服务的权限。

取消请求后，领域层标记旧 generation 无效。即使底层推理无法立即中断，迟到结果也不会进入当前课程状态；持续取消造成资源占用时重启 worker，录音继续。

## 5. 桌面权限

Tauri capability 只开放需要的命令、窗口和文件范围，按官方机制限制前端可调用能力。[S16] 页面使用严格 CSP，禁止任意远程脚本，用户内容通过安全文本或已清理的富文本节点渲染。

权限引导区分麦克风、系统声音、文件选择与网络模型下载。原生模块需要的具体系统授权在每个平台实际验证。权限被撤回时停止对应采集并说明恢复路径。

## 6. 模型供应链

模型清单含来源 URL、许可证、完整源提交、文件 SHA-256、文件字节数、运行库兼容版本、decoder/mmproj 配对关系和构建信息。开发前期允许清单中的校验值为空并标 `unverified`，发布检查必须拒绝该状态。

下载采用 HTTPS、来源允许列表、断点续传和完整校验；校验完成后原子安装。更新不能用同名文件替换正在使用的权重。原生二进制由发布构建签名，模型文件可单独校验和更新。

## 7. API 接入边界

接口设计预留云端适配器。启用时逐项确认提供方、会发送的音频范围、密钥存储方式和网络状态。密钥存入系统凭据管理工具，配置数据库只保存引用。

首版实现云端适配器时，默认发送明确选择的录音片段，排除用户图片、公式和独立笔记。模型故障、弱网和 API 限流均保留本地队列；本地与云端切换由用户动作触发。提供一键恢复纯本地模式并终止新上传的入口，已发出的请求按提供方实际取消能力处理。

## 8. 威胁与缓解

| 风险 | 必须的处理 |
|---|---|
| 其他网页调用本机服务 | 回环绑定、随机凭据、限制来源、Rust 代理、关闭无关端点 |
| 本地同账户恶意程序 | 说明 OS 账户信任边界，保护文件权限与密钥，避免夸大隔离 |
| 转写中出现 HTML 或指令 | 当普通文本处理，禁用任意脚本和工具执行 |
| 恶意图片或公式 | 限制大小与解码量、安全解析、KaTeX 非信任模式 |
| 导入 ZIP 路径穿越或压缩炸弹 | 规范化路径、禁止绝对路径、限制展开量与条目数 |
| 隐私写入日志 | 默认元数据日志、字段白名单、用户审阅后导出诊断 |
| 更新或模型文件被替换 | 来源校验、哈希、签名、原子安装与版本锁定 |

录音合规由使用情境决定。应用提供提醒、明确录音状态、易用的停止与删除入口，不替用户假定课堂或会议已经获准录制。
