# 08 · 视觉规范与动效

## 1. 设计方向

采用适合长时间阅读的浅色文档界面，借鉴 Notion 的内容层级和 Apple 桌面应用的细致状态反馈。整页以文字、留白、轻量分隔和少量状态色组织。下列颜色、尺寸与时间全部是本产品的设计提案，后续通过原型和真实设备调整。

视觉中心是正在听的课程内容。课程导航弱化；录音状态始终可见；编辑面板出现时占有稳定空间。课程文档本身保持自然阅读节奏。

## 2. 基础设计变量

| 类别 | 建议值 |
|---|---|
| 应用背景 | #F7F7F5 |
| 面板与文档背景 | #FFFFFF |
| 正文 | #232323 |
| 辅助文字 | #73716D |
| 分隔线 | #E7E5E1 |
| 主要强调色 | #3C6E71 |
| 编辑中底色 | #F0F5F3 |
| 待核对底色 | #FFF5DF，正文另用深色 |
| 录音指示 | 深红圆点配“录音中”文字，避免只用颜色表达 |
| 间距基础 | 4、8、12、16、24、32 像素 |
| 圆角 | 输入框 8，面板 12，资料卡 8 像素 |
| 分隔线 | 1 像素，减少多层嵌套边框 |

`design/tokens.css` 是可直接迁移的变量文件。实际文字组合以相应背景上的对比度测试为准。

## 3. 字体与阅读

使用操作系统字体栈：macOS 采用系统 UI 字体，Windows 使用 Segoe UI，中文由系统中文字体回退。避免将 Apple 字体文件打包到跨平台安装程序中。

正文建议 17 像素、行高 1.65；编辑区 16 至 17 像素；时间戳 12 像素并使用等宽数字；课程标题 22 至 26 像素。提供 15、17、19 三档文字大小。英文正文使用正常字距，中文与混合文本允许自然换行。

转写阅读列的理想文本宽度约 680 至 760 像素。时间戳位于块顶部或左侧窄栏，进入编辑时提供更完整的音频范围。

## 4. 主要尺寸

以 1440×900 桌面视口作为设计稿基准，以 1280×800 和 1366×768 作为适配检查点。顶部控制区约 56 像素，导航折叠宽约 64 至 72 像素，展开宽约 220 像素。

编辑面板建议宽 380 像素，可拖动到 340 至 460。右侧使用剩余空间，正文至少保留约 480 像素。窗口较窄时自动折叠课程导航；小于约 1050 像素时采用编辑与记录切换页，并保留底部三行最新转写预览和录音状态。首版最小窗口尺寸建议 960×640。

面板切换使用一次布局切换，随后对内容进行短位移和透明度动画。避免连续改变正文列宽，使换行和光标位置反复变化。

## 5. 转写块状态外观

临时结果使用正常正文加轻量“正在识别”标记。稳定结果移除标记。人工修订显示简洁铅笔图标和可访问标签，点击可查看原识别。编辑中的块使用淡底色与左侧细线。待核对块显示小型状态标签，完整比较放在专门面板。

每个状态同时具有文字或图标提示。状态图标默认静止；录音圆点可以低频轻微变化，但始终支持关闭。模型输出不增加人为逐字打字动画，避免额外延迟和视觉负担。

## 6. 动效表

| 事件 | 建议时长 | 动作与边界 |
|---|---|---|
| 按钮悬停与聚焦 | 80–120 ms | 底色或描边变化 |
| 编辑面板出现 | 160–200 ms | 内容最多约 6 px 位移加透明度 |
| 保存修订原位反馈 | 180–220 ms | 原块轻量底色变化，保持高度与滚动锚点 |
| 菜单出现 | 100–140 ms | 透明度，轻微缩放可选 |
| 非紧急提示 | 可见约 2 s | 静态文字，自然淡出；重要错误保留 |
| 返回最新 | 用户显式触发 | 短距离平滑滚动；长距离直接定位并提示 |

统一缓动建议 `cubic-bezier(0.2, 0, 0, 1)`。动画不作为保存成功的计时器；持久化回执决定状态变化。转写更新合并为可预测批次，限制大量元素同时动画。

## 7. 减少动态与无障碍

遵循系统 `prefers-reduced-motion` 设置，在应用内提供“跟随系统、减少动态”选项。浏览器媒体查询能读取用户的减少动态偏好。[S23] 减少模式保留必要状态变化，去掉位移、缩放和自动平滑滚动。

Tab 顺序依次经过主要录音操作、记录区、编辑区和资料操作。所有图标按钮有可读名称。焦点环清楚可见。读屏默认读取用户关注的块，完整实时文本不逐 token 播报；可选按最终块进行轻量通知。

编辑器必须通过中文输入法、重音字符、emoji、组合字符、粘贴和撤销测试。任何机器更新都不改写当前编辑器的 selection。

## 8. 状态文案

推荐文案包括“录音中”“录音已结束”“正在加载本地模型”“转写落后约 8 秒”“草稿已保存”“修订已保存”“此段有识别更新待核对”“音频来源已断开”“磁盘空间不足，录音已停止”。

数字来自实际状态与测量。加载无法估算剩余时间时显示当前步骤；没有置信度时使用真实处理状态。模型名称放在状态详情中，普通操作围绕课程与文字组织。

## 9. 原型验证与交付要求

实现界面时交付三组真实运行截图：空课程与设备检查、录音中左侧修订、录音结束后的资料整理；再录一段完整“机器追加—用户修改—原位提交—继续跟随”的操作视频。截图与视频分别在 Windows 和 macOS 获取，并注明系统与窗口尺寸。

检查正文是否抖动、面板是否抢焦点、按钮是否触发两次、长单词是否溢出、插图是否撑破宽度，以及旧段落在新内容加入后是否仍位于同一视觉位置。
