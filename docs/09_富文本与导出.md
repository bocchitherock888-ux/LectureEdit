# 09 · 富文本与导出

## 1. 文档模型

课堂文档由转写块和人工资料块组成。转写文字由领域层计算，编辑通过独立草稿提交。人工资料使用结构化富文本 JSON。两类内容通过稳定锚点在同一阅读视图组合。

Tiptap 提供数学节点与 KaTeX 集成，可用于行内及块级公式。[S21] 初始实现只启用必要节点：段落、加粗、斜体、列表、链接、公式、图片与案例容器。转写流直接写入领域存储，避免将自动更新频繁注入整个富文本文档事务。

## 2. 资料类型

| 类型 | 最小字段 | 用户操作 |
|---|---|---|
| 备注 | rich_text_json、来源说明 | 自由输入、移动、折叠 |
| 公式 | latex、display_mode、说明 | 编辑源码、预览、复制 |
| 图片 | asset_id、alt、caption | 粘贴、拖入、替换、缩放 |
| 例子 | title、rich_text_json、source_label | 标注教师例子或自己的例子 |

资料放在指定转写块前后，并可在同一锚点下排序。首次插入先确定目标块；光标处于独立资料编辑器时，默认继续插入到该资料上下文，避免新转写改变插入目标。

## 3. 公式规则

公式编辑保留用户 LaTeX 源码，渲染失败时保留可编辑状态。限制输入长度、宏展开次数与渲染时间，KaTeX 设置 `trust: false`。链接和 HTML 扩展按安全规则禁用或清理。

自动语音转公式安排为后续可选功能。首版用户可以粘贴 LaTeX、手动输入或插入公式图片。独立公式源始终进入导出，避免只保存预览像素。

## 4. 图片处理

优先支持 PNG、JPEG、WebP。建议单张文件上限 10 MB、解码像素总量上限 20 MP；这是初始安全限制，可在导入前给出调整提示。检查真实文件类型、尺寸和解码结果，拒绝伪装扩展名与异常文件。

默认生成用于显示的安全栅格副本，处理方向并去除不必要的 EXIF 定位信息。保存内容哈希、原始名称的安全显示版本和用户说明。用户可选保留原文件，原文件作为附件处理，不直接注入页面。

SVG 先转换为安全栅格预览，或通过专门清理器后开放。所有图片资源通过受控协议读取，路径由 asset ID 映射，页面不能读取任意本地文件。

## 5. 编辑与撤销边界

资料块使用自身修订号。编辑器的短期文字撤销在本块内运行；提交与移动资料进入文档人工操作历史。机器追加独立处理，保持用户撤销的可预测性。

资料块高度变化后由视图锚点服务补偿滚动。图片预先保存宽高比例，以便加载前预留空间。长公式支持横向滚动或独立展开，避免扩大整份文档宽度。

## 6. 导出矩阵

| 格式 | 首版 | 保存内容 |
|---|---|---|
| Markdown + assets 文件夹 | 支持 | 修订后文字、时间、资料、LaTeX、相对图片路径 |
| 自包含课程阅读 HTML | 支持 | 修订后文本、资料、可用的音频片段定位、缺口与待核对标记 |
| 原生课程包 ZIP | 支持 | 文档、音频、附件、来源与可选完整历史，可再次导入 |
| WAV | 支持 | 标准录音，按需分卷并附缺口说明 |
| SRT/VTT | 可选 | 具有可靠范围的转写块；人工笔记排除 |
| DOCX/PDF | 后续 | 经公式、字体和分页专项验收后提供 |

导出 HTML 使用应用随附的已审核脚本或静态内容，核心阅读不依赖网络 CDN。课程文件较大时音频作为相对资源放在导出目录或课程包中；“单 HTML 文件”仅对明确体积上限的小型导出开放。

## 7. 内容来源

导出默认展示用户修订后的文字，并附简洁说明“含人工修订，时间戳按音频块”。未解决候选在文末或对应段落标为待核对，可选择附机器原文。教师讲话与用户笔记在样式和结构上保持区分。

导出快照绑定 `operation_seq`；导出期间继续录音或编辑时，新内容留待下一次导出。界面显示导出覆盖的课程范围和快照时间，避免用户误以为包含尚未处理音频。

## 8. 搜索与复习

初版支持在当前课程搜索修订后的文字与用户资料，结果包含时间与回放入口。高亮范围依据当前文本计算，机器更新后重新求值。跨课程全文检索可在本地 FTS 索引建立后扩展。

单词级同步高亮需要有效的词级时间戳。强制对齐后每条结果存储文本哈希与对齐模型版本，后续修订使对应对齐失效。块级播放始终可用，除非音频本身存在明确缺口。
